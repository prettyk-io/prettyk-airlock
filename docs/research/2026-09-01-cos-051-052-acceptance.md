## Accepted behavior

- Every provider reports the same capability taxonomy.
- Unknown or undocumented capability is not treated as supported.
- Unsupported operations return explicit `UNSUPPORTED`, never fake success.
- Provider identifiers do not replace PureK canonical digest/revision identity.
- Sfera raw and OCI push/pull preserve provider digest where available.
- Sfera provisioning routes remain configurable and return honest unsupported
  until CORE API routes are confirmed.
- Provider errors map to transfer failure categories without masking.
- Kernel files and semantics were not modified.
